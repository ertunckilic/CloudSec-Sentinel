# Security Policy for CloudSec Sentinel

## Supported Versions
We provide security updates only for the latest major version.

| Version | Supported |
| ------- | --------- |
| 1.0.x   | Yes       |
| < 1.0   | No        |

## Reporting a Vulnerability
As a security-first platform, we take vulnerabilities seriously. DO NOT open a public issue for security flaws. Report them directly to the repository owner. We commit to a 24-hour acknowledgement and a 48-hour patch SLA for critical CVEs.
